The name of the piece is “Public Telephone”

To use the public telephone:
First   DO NOT PULL THE CHAIN  if the doors are restricted from movement. Make sure the box is properly mounted and ready to use before pulling the chain. This could damage some of the mechanical movements. (see box mounting) Do not try to open or close the doors manually. 
OK now that that is out of the way, pull the chain….
The doors should immediately open and you will hear a dial tone. (there's a little blue knoby thing to adjust the volume if it’s too soft or too loud.)
Dial a number. If you do not dial a number the operator will come on and instruct you to hang up and try again. 
Doors will automatically close.
Wait a second and pull the chain again. Dialing a number will give you different messages after which the doors will close again.
You can dial a number while a message is playing.
Sometimes you might dial a number while the doors are going shut. No worries. Wait for the message to finish and pull the chain again.



Box Mounting:
The thing has a really sturdy rail mounting system to handle user abuse
Mount the wall rail piece with 4 drywall screws. (there is a level built into it so you can get it strait)
Then just hook the box on the rail and you're good to go.

Charging:
The battery will eventually run down. 
The battery pack is not removable.
On the right side there is a hole where you can insert a charge cable
It requires a micro usb cable 
Just plug it into any standard USB charger
Little blue lights will indicate the charge level

Files need to be saved in a specific format and the file names need to be the same so the program knows where to find them.
